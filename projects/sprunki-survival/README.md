# Sprunki Survival Handbook

A calm, kid-friendly handbook page for the Sprunki crew: one card per character with a short friendly description and a care tip.

- Open `index.html`. No build step, no network, no storage.
- Characters live in `js/data.js`. Pictures are optional, see `ASSETS_GUIDE.md`.
- Different from `games/sprunki` (the mixer game) and `games/sprunki_v2`.
