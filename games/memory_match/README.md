# Memory Match

A gentle flip-the-cards pairs game for young children. No timer by default, no losing, no streaks, no accounts, no network, no ads.

## Play
Open `index.html` (works from file:// and GitHub Pages) or visit games/memory_match/ on the site.
- Tap a card to flip it. Flip two per turn. Matches stay face up. Mismatches flip back after about 0.9 seconds. Tapping any card during that wait flips them back at once and flips the card you tapped.
- Sizes: Easy 3x4 (6 pairs, default), Normal 4x4 (8 pairs), Big 4x5 (10 pairs).
- Card sets: Emoji (21 Unicode emoji) and Animals (14 original SVG drawings).
- Gear button: size, card set, optional timer (off by default). Speaker button: mute (remembered). Restart button: new deal.
- Win: confetti, "Play again", "Change size". Best (fewest moves) is kept per size and set.
- Keys: arrows move between cards, Enter or Space flips, Esc closes settings.
- Home (top left) goes back to the arcade.
