# Jigsaw - Changelog

## 2.0.0 - 2026-10-29
Full rebuild.
- Pure, unit-tested geometry, groups and model modules (node tests/run.js).
- Seeded jigsaw edges (same seed, same puzzle), Square and Rounded shapes.
- Snap to neighbours and board, transitive groups, lock toggle, snap slider, Little hands.
- Pointer events with capture, multi-touch, pinch/wheel zoom, pan, Fit, keyboard play.
- Pictures: file, camera, drop, paste, 8 original samples, EXIF fix, downscale to 1600, friendly errors.
- Save and resume (localStorage + IndexedDB), My pictures shelf (12), puzzle file export and import.
- Shuffle, Edges, Ghost, Peek, Hint, optional turning, confetti (reduced-motion aware), FongCheer hooks.
- Removed the always-visible timer. Old `jigsaw_*` v1 keys are ignored.

## 1.1.0 - 2026-03-07
Rounded tab shape, lift effect, snap sound (v1, replaced).
