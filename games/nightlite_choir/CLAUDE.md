# Nightlite Choir+: notes for LLMs

Read [IP-GUARDRAILS.md](IP-GUARDRAILS.md) first and follow it. Then [DESIGN.md](DESIGN.md). Do not open the My Singing Monsters wiki. Do not reuse the S4K Classic pack. Code in `js/synth.js` and `js/art.js` was copied from `games/sprunki_v2` and is ours. Standalone folder, strict ES5, relative paths, all 7 docs kept current. PR into `dev`, never push to `dev` or `main`.

State (v0.3.0, Milestone 2b): door screen plus all three worlds (Night Garden, Toy Attic, Star Observatory), one shared stage, tempo from the first creature, a world switcher (chips) in the tray. Next: eggs, sparks and combining (Milestone 3). File layout is in [ARCHITECTURE.md](ARCHITECTURE.md). The Attic and Observatory creatures are generic ideas only (rag doll, hobby horse, tin wind-up toy, plush unicorn, sleepy moon, star with a lightstick wand, comet, ringed planet): never copy a recognizable character, outfit or name from any film, show, game or webtoon. To add a creature: add an entry to a file in `js/worlds/` (C pentatonic only, one job each), run the name check, log it in [ASSET_LOG.md](ASSET_LOG.md). Storage keys start with `nightlite.`. Keep peak volume gentle (master cap in app.js).
