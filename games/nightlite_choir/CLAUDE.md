# Nightlite Choir+: notes for LLMs

Read [IP-GUARDRAILS.md](IP-GUARDRAILS.md) first and follow it. Then [DESIGN.md](DESIGN.md). Do not open the My Singing Monsters wiki. Do not reuse the S4K Classic pack. Code in `js/synth.js` and `js/art.js` was copied from `games/sprunki_v2` and is ours. Standalone folder, strict ES5, relative paths, all 7 docs kept current. PR into `dev`, never push to `dev` or `main`.

State (v0.2.0, Milestone 2a): door screen plus the Night Garden and the Toy Attic (shared stage, tempo from the first creature). The Star Observatory is next. File layout is in [ARCHITECTURE.md](ARCHITECTURE.md). The Attic creatures are generic toy ideas only (rag doll, hobby horse, tin wind-up toy, plush unicorn): never copy a recognizable character, outfit or name from any film, show, game or webtoon. To add a creature: add an entry to `js/worlds/garden.js` or `js/worlds/attic.js` (C pentatonic only, one job each), run the name check, log it in [ASSET_LOG.md](ASSET_LOG.md). Storage keys start with `nightlite.`. Keep peak volume gentle (master cap in app.js).
