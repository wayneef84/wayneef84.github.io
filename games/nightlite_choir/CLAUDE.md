# Nightlite Choir+: notes for LLMs

Read [IP-GUARDRAILS.md](IP-GUARDRAILS.md) first and follow it. Then [DESIGN.md](DESIGN.md). Do not open the My Singing Monsters wiki. Do not reuse the S4K Classic pack. Code in `js/synth.js` and `js/art.js` was copied from `games/sprunki_v2` and is ours. Standalone folder, strict ES5, relative paths, all 7 docs kept current. PR into `dev`, never push to `dev` or `main`.

State (v0.4.0, Milestone 3): door screen plus all three worlds (Night Garden, Toy Attic, Star Observatory), one shared stage, tempo from the first creature, a world switcher (chips) in the tray with a fourth chip for Blends. Sparks (free, trickle while playing, cap 99, free Wish button), eggs in a nest (tap to warm), a Mixing pot with an invented recipe table, a Discovery book and 6 blend creatures in `js/worlds/blends.js`. Next: Milestone 4 (polish, final docs). File layout is in [ARCHITECTURE.md](ARCHITECTURE.md). The Attic and Observatory creatures are generic ideas only (rag doll, hobby horse, tin wind-up toy, plush unicorn, sleepy moon, star with a lightstick wand, comet, ringed planet): never copy a recognizable character, outfit or name from any film, show, game or webtoon. To add a creature: add an entry to a file in `js/worlds/` (C pentatonic only, one job each), run the name check, log it in [ASSET_LOG.md](ASSET_LOG.md). Storage keys start with `nightlite.`. Keep peak volume gentle (master cap in app.js).


Milestone 3 rules: the 12 base creatures stay free and always available. Blends are extra things to collect. Never add timers that punish, streaks, daily bonuses, countdown pressure, ads, purchases or a network call. Keep the sparks free. Recipes, costs and numbers are invented here: do not copy any other game's creature combinations or structure, and avoid the vocabulary listed in IP-GUARDRAILS.md. No tier or grade labels on creatures. New blend: add an entry in `js/worlds/blends.js` (two parents from different worlds, C pentatonic, own role), add the name check in [ASSET_LOG.md](ASSET_LOG.md), update the recipe table in [DESIGN.md](DESIGN.md).
