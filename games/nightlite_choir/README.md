# Nightlite Choir+

A cozy music game for a young child. Hatch little creatures from eggs, put them on a stage and their loops layer into a song. Three worlds: the Night Garden, the Toy Attic and the Star Observatory.

Status: design only. See [DESIGN.md](DESIGN.md). Rules for LLMs: [IP-GUARDRAILS.md](IP-GUARDRAILS.md).
