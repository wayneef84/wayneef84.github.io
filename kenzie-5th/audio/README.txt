KENZIE BIRTHDAY - OPTIONAL RECORDED VOICES

IMPORTANT: recording lookups are switched off. After adding files, set CLIPS_ENABLED=true near the top of the script in index.html.
(A clip is checked the first time its line is spoken, so it plays from the second time on.)

Drop recordings in this folder (next to index.html). Name each file <characterId>-<n>.mp3 or .m4a.
If a file exists the page plays it instead of the computer voice. If it is missing the computer voice is used,
and if the tablet has no working voice the page shows the words on screen with a glowing word-by-word highlight.
You can record only some lines. Say the line exactly as written (the glow is spread evenly across the clip length).
Record in your own voice or a family member's voice. Do not use copyrighted audio or imitate real actors.
Tip: keep clips short, mp3 or m4a, mono. Reload the page after adding files.
The sound check button on the cover plays unicorn-15 and tells whether a recording or voice is working.
torn-N lines are the tornado parade, in the order of the entries marked parade:true in TORNADOS (top of index.html).
If you change a tornado name, nickname or line in TORNADOS, record the new wording.
